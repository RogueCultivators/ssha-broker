    • 用 ssha ui 在终端里打印的那条地址打开，形如 http://127.0.0.1:8770/?token=…。

    接入 agent

    skill 告诉 agent 怎么用 ssha，装到下面任一位置即可。

    MCP 配置

    放进对应客户端的配置里再重启它。skill 和 MCP 二选一就行，也可以都用。

    主机

    agent 靠这段文字找机器。写清跑什么、单元名、日志路径。

    登录方式

    保存在 secrets/ 下（0600），加密保存，不进配置文件，界面不显示原文。

    高级：自己指定文件或环境变量

    环境变量优先于文件。上面输密码时会自动清掉它，并在结果里说明。

    高级设置（主机密钥、策略覆盖、跳板机、标签）
    主机密钥

    留空则用 ~/.ssh/known_hosts；查不到就拒绝连接。

    策略

    其他

    Git

    账号留在这台机器上。Agent 只能请求 push / fetch，看不到密码和私钥。
    账号

    主机名是 github.com 这种，不是整段 clone 地址。自建 Git 可以带端口，比如 git.example.com:14444；不带端口就匹配所有端口。路径前缀更长的账号优先，用来把同一个主机上的不同组织分开。

    认证

    界面里输入的密码会加密保存。Agent 和命令行都读不到原文，也不会出现在审计日志里。

    允许的操作

    选一条记录，在这里看命令和输出。

    设置

    外观

    只影响这个窗口，存在本机。

    全局策略

    给所有主机的默认值。哪台主机自己覆盖了，就以那台为准。留空表示用程序内置的默认。

    审计

    关掉之后审计里只有命令和结果，没有输出内容。改日志路径请编辑配置文件。

    管理密码

    只用来打开这个界面，不参与 SSH 登录，命令行也不问它。
